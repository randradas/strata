# Architecture decision records

File name: `NNNN-short-title.md`, numbered from the highest existing one. Never edit an accepted ADR; supersede it.

Write one only when a decision is hard to reverse, surprising to a future reader, and the result of a real trade-off.

Template:

```markdown
# NNNN. Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

1-3 sentences: the context, what we decided, and why.
```

Optional sections, only when they add value: Considered options, Consequences.
